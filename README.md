# 쇼핑몰 장바구니 & 할인 쿠폰

터미널에서 동작하는 온라인 쇼핑몰 장바구니 프로그램

## 실행 방법

main.py 실행 후 번호 선택 후 원하는 기능 선택 후 결제하면 됨.

## 구현 기능

- 상품목록 (`product_list`): 상품 번호, 가격, 재고 출력
- 담기 (`add_p`): 장바구니에 수량 추가
- 빼기 (`minus_p`): 장바구니 수량 제거
- 장바구니 (`cart`): 상품 합계, 할인, 배송비, 결제 금액 출력
- 쿠폰 (`coupon`): 쿠폰 1장 선택 적용
- 결제 (`cash`): 영수증 출력, 재고 차감, 장바구니·쿠폰 초기화
- 종료: q 입력

## 클래스

- Product: 상품 정보
- Discount: 할인 부모 클래스
- RateDiscount: 비율 할인
- FixedDiscount: 정액 할인
